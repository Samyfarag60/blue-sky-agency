## Enable GitHub Pages
1. Go to https://github.com/Samyfarag60/blue-sky-agency/settings/pages
2. Source → Deploy from a branch → **main** → **/ (root)**
3. Click **Save**
4. Wait 1–2 minutes — the site will be live.
